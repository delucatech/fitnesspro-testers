This button only works on an iPhone or iPad. Open this page there, in Safari.

How to install

  1. Tap Install, then Install again when the iPhone asks.
  2. Go to the Home Screen. The FitnessPro icon fills in while it downloads, about a minute on Wi-Fi.
  3. Open FitnessPro. There is nothing to trust or switch on in Settings.
  4. Check the build. Open the More tab and scroll to the bottom. It should say build 20261120-2141.
Nothing happens when I tap Install

Open the page in Safari itself. The browser inside Gmail, Messages or another app often blocks the install. Copy the link and paste it into Safari.

After the first tap the page stays as it is; the download runs on the Home Screen, not here.

"Unable to install" or "integrity could not be verified"

This build only installs on the iPhones and iPads registered for testing. A new device has to be added first, and then it needs a build made after that.

To add one, send its identifier (UDID). With the iPhone plugged into a Mac: Finder, select the iPhone, and tap the line under its name until the UDID shows.

Good to know

It works on Wi-Fi or cellular. Installing a newer build from this page keeps your data; deleting the app removes it.

This build stops opening on August 28, 2027, when its signing runs out. A later build will replace it before then.
